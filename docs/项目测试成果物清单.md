# 项目测试成果物清单

本目录用于保存“知序教学辅助网站”的阶段性测试成果物，方便课程验收、阶段开发和后续复盘。

## 已形成成果物

### 1. 阶段性测试成果报告

文件：

```text
docs/测试阶段性成果报告.md
```

用途：

- 给老师说明项目当前已经测试到什么程度
- 记录测试思路和阶段成果
- 项目复盘时记录发现的问题和解决方案

主要内容：

- 服务可用性测试
- 账号与权限测试
- 课程与实验指导测试
- 在线 Python 运行测试
- AI 助教交互测试
- 自动化冒烟测试结果
- 后续测试计划

### 2. 测试用例清单

文件：

```text
docs/测试用例清单.md
```

用途：

- 说明项目不是随便点点页面，而是有测试项、有预期结果、有测试状态
- 后续可以继续扩展为 Excel 表格或正式测试文档

覆盖模块：

- 服务可用性
- 登录与权限
- 课程学习
- 实验指导
- 在线 Python
- AI 助教
- 数据记录

### 3. 自动化冒烟测试脚本

文件：

```text
tools/smoke_check.py
```

用途：

- 快速检查网站核心链路是否还能跑通
- 每次演示前可以先跑一次，避免现场出问题

覆盖内容：

- 后端健康检查
- 三角色登录
- 学生读取课程
- 管理员查看账号
- 学生越权拦截
- 实验指导读取
- 在线 Python 中文输出

运行方式：

```powershell
cd E:\codex\教辅网站开发
.\backend\.venv\Scripts\python.exe .\tools\smoke_check.py
```

### 4. 实际问题修复记录

本阶段测试中已经发现并解决的问题：

| 问题 | 原因 | 解决方式 | 状态 |
| --- | --- | --- | --- |
| 后端依赖缺失 | 当前 Python 环境缺少 FastAPI/uvicorn | 创建 `backend/.venv` 并安装依赖 | 已解决 |
| 实验指导不存在 | 数据库中缺少 `guess-number` 实验指导 | 通过教师端接口补充实验指导 | 已解决 |
| `input()` 代码报 `EOFError` | 标准输入为空或输入不足 | 增加标准输入说明和默认示例 | 已解决 |
| AI 助教不能拖动 | 原悬浮窗固定在右下角 | 增加拖动逻辑 | 已解决 |
| AI 助教刷新后位置丢失 | 未保存拖动坐标 | 使用 `localStorage` 保存位置 | 已解决 |
