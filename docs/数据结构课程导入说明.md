## 怎么使用

1. 在本机打开 `http://127.0.0.1:4173/`，选择“课程学习 → 数据结构（Python）”。
2. 展开章节，选择知识点，阅读讲义或翻阅原版课件；回答小测后保存该节完成状态。
3. 在“在线练习”左侧按课程、章节、知识点选择讲义，右侧编写 Python；编程知识点可载入练习示例。
4. 点击“下载本章配套资源”或“下载配套资源”，取得该章原始资料。
5. 教师继续通过既有课程管理入口修改章节、正文、小测以及上传课件和预览 PDF。

课堂实践中的理解小测不等同于算法作业批改。原题库以配套文件提供，尚未转换成完整在线题库。

## 维护脚本

在项目根目录执行：

```powershell
python tools/build_data_structure_assets.py
powershell -NoProfile -ExecutionPolicy Bypass -File tools/export_course_previews.ps1
```

第一条整理源资源、打包附件；原 PPTX 内容变化时使对应旧 PDF 失效。第二条使用本机 PowerPoint 导出缺少的 PDF，需要安装 PowerPoint。

生成文件在 `backend/assets/data-structures`。这些脚本用于维护发布资源，不会把新生成内容强行覆盖到老师已编辑的数据库课程；正式修改已发布课程仍应通过教师端完成。

运行自动测试：

```powershell
cd backend
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

本次没有提交或推送 GitHub，也没有将网站部署到公网。
