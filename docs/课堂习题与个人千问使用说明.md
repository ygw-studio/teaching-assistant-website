# 课堂习题与个人千问

学生个人中心的“个人千问 API”设置中有“如何获取 API Key”入口。默认收起，展开可按操作一至五查看提供的教程图，点击图片可查看原尺寸大图。复制自己的 Key 后，应先在百炼为所用模型开启“免费额度用完即停”，再回到设置中完成绑定；不要复制教程截图中的密钥内容。教程图片位于 `frontend/public/guides/qwen-api/`。

更新日期：2026-10-06。本轮是本机功能更新，不代表已满足学校服务器上线条件。

## 三角色入口

- 学生：在线练习选择教师发布的习题，左侧讲义、右侧 Notebook；支持运行、自动保存、提交和再次提交。不展示学习时长，后台继续计时与保存记录，教师和管理员仍可查看。
- 教师：作业管理新增、编辑、发布或撤回习题，设置截止时间；学生记录查看负责课程的做题、提交、代码版本及 AI 对话，导出 CSV。
- 管理员：学习数据查看全平台记录、运行简单清理；课程负责人和学生名单决定新习题及学习记录的访问范围。

已有开发课堂首次迁移时，将数据结构课程关联原有演示教师与现有学生，并把已有教师实验文字内容迁移为习题。此关联只执行一次，后续管理员修改不会在重启时恢复。新账号由管理员分配到课程。

## 个人千问 API

1. 学生登录自己的平台账号，进入个人中心。
2. 在阿里云百炼北京地域创建通用 API Key，确认所选模型有可用额度。
3. 在百炼控制台为该模型开启“免费额度用完即停”，等待设置生效。
4. 在个人中心填写 Key、模型编号并确认上述设置，绑定后打开 AI 助教自由提问。

绑定动作本身不请求模型，也不验证 Key 是否有效；首次实际聊天才进行调用。没有预设提问按钮，不强制启发式提示。对话按账号与习题关联，刷新、关闭再打开时可恢复。

平台只调用当前用户配置的 Key，不回退到原有平台 DeepSeek/AI Key。免费额度不是永久额度，网站不能读取或保证用户百炼账户中的计费开关；未开启官方保护时仍可能计费。403 返回可能来自额度、模型权限等原因，不能一律认定为余额不足。

Key 不回显、不写行为日志或 CSV。开发环境首次绑定生成 `backend/data/.ai-credential-encryption.key`，与数据库一起保存在被 Git 忽略的数据目录。恢复数据库时必须同时恢复该加密配置；生产环境必须通过独立秘密管理配置 `AI_KEY_ENCRYPTION_KEY`，不得把 Key 或加密配置上传 GitHub。实际部署还需要 HTTPS、服务器文件权限、备份保护。

## 截止时间与版本

教师输入本机时区的截止时间，后端存储 UTC，页面时间按北京时间显示。空截止时间表示不限。

截止后后端拒绝提交，不依赖学生电脑时间；教师延期后可继续提交。重复点击或网络重试采用提交编号去重。首次提交时间保留，再次提交另存版本。习题内容修改保留版本，已有做题记录继续关联原题版本；截止时间修改对已有尝试生效。撤回不删除历史记录，已开始的学生可查看原内容，不能提交。

## 行为记录与时间口径

原始明细位于现有数据库的 `learning_events`。同时保留客户端发生时间和服务器接收时间，账号由登录凭证确定。页面、讲义翻页与缩放、点击、滚动、单元格编辑操作类型与字符数、粘贴字符数、单元格变化、运行与结果、提交、AI 打开收起及对话等分别记录。

编辑事件不保存每次按键的文本；运行、提交时保存关键代码版本到 `code_snapshots`，完整提交保存在 `task_submissions`。对话正文保存在 `chat_messages` 并与尝试关联。不会收集未发送的 AI 输入、API Key 输入、密码输入和平台外活动。

高频滚动按 750 毫秒采样；编辑事件保留发生时间，批量上传。前台可见时间与 AI 面板展开时间按约 15 秒片段累计，切后台、换学习上下文、收起 AI 或离开时结算。多标签页重叠区间取并集，避免重复计算。进程运行耗时、AI 回复等待、做题经过时间、页面可见时间是不同指标。

页面可见不代表学生实际注意力或理解。时间为可观测的估算；强制关机、浏览器崩溃等可能丢失最后尚未持久化的片段。事件保留原编号重试，未同步事件保存在按账号和标签页隔离的本机队列；网络恢复、刷新或该账号重新登录时尝试补传。延迟超过五分钟或时钟偏差的记录带质量标记，不纳入默认时长汇总，但原始记录仍保留。

## 简单清理与导出

管理员“运行简单清理”，或在后端执行：

```powershell
.\.venv\Scripts\python.exe scripts\clean_learning_events.py
```

统一 UTC 时间、生成缺失与异常标记，结果存入 `learning_events_clean`；不覆盖或删除 `learning_events`。传输重试按事件编号去重。CSV 包含学生、课程、习题、尝试、事件类型、发生时间、接收时间、元数据和质量标记；按登录角色限制导出范围，并处理电子表格公式注入风险。

## 当前限制

- Notebook 仍在本机开发环境运行，上线前需要隔离沙箱，现有内核数量上限仍为 8。
- 暂未进行真实千问 Key 调用验收或 100 人并发容量验收，不保证教学效果或统计因果结论。
- 上线前需另行确定学生告知、数据用途、保留期限、研究匿名化和访问管理。
