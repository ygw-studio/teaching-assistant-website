# 后台学习记录查看说明

更新日期：2026-10-04。

## 学生端与后台的区别

学生端保留课程进度、答题反馈、代码运行结果和正常 AI 对话功能，不展示学习行为时间线、AI 提问次数、代码运行次数或“学习数据”入口。学生首页接口不再返回这些行为统计或历史明细。

隐藏学生端展示不会停用或删除后台记录。个人主页保留简短的数据用途说明，不显示行为记录明细。

## 当前数据库

核实正在使用的数据库为：

`E:\codex\教辅网站开发\backend\data\teaching-platform.db`

不要用 VS Code 的普通文本编辑器打开或保存 `.db`，它是 SQLite 二进制数据库。可使用 SQLite 数据库查看器，以只读方式打开，选择以下数据表：

| 表 | 保存内容 |
| --- | --- |
| `audit_events` | 登录、退出、代码执行等操作；含账号、事件类型、对象、发生时间和附加信息 |
| `lesson_quiz_attempts` | 小测每次回答、是否答对、对应课程和知识点、提交时间 |
| `lesson_progress` | 已完成的知识点及完成时间 |
| `chat_messages` | AI 对话消息、发送者、所属账号、时间 |
| `conversations` | AI 会话及会话创建、更新时间 |
| `code_drafts` | 按账号和练习保存的当前代码草稿，以及创建、更新时间；不是全部编辑历史 |

核查时数据库已有 133 条审计事件、2 条对话消息。小测、知识点完成和代码草稿表当时为 0 条，不能把没有发生过的操作当作已经收集到的数据。后续操作会继续增加或更新记录。

例如查看最新操作，可在数据库工具中运行以下只读 SQL：

```sql
SELECT account_id, event_type, resource_type, resource_id, created_at, metadata
FROM audit_events
ORDER BY created_at DESC
LIMIT 50;
```

## 日志与学习数据

`backend/server-student-privacy.out.log`、`backend/server-student-privacy.err.log` 是本次重启后的服务运行日志。它们主要用于查看请求状态、启动信息与错误，不是完整的学生行为数据集。

用于后续研究和分析的数据应从数据库提取。时间戳以 UTC 保存，转换为北京时间时需加 8 小时，保留原始时区信息。

代码执行事件当前保存执行耗时、退出状态和关联练习等信息；执行耗时不等于学生完成实验的总学习时间。现在没有完整记录阅读停留、离开页面、编辑全过程或作业完整耗时，不应声称这些已经采集完成。

教师端“学生记录”页面目前仍是说明页，尚未接入完整查询。现阶段可以直接查看数据库；后续受限的查询或导出入口应只对授权教师、管理员开放，不能直接给学生返回这些后台行为数据。

## 验证

后端测试覆盖：学生首页接口只返回课程与完成进度，其他账号的完成情况不会混入；隐藏统计后，审计事件、AI 对话、小测回答和完成状态仍保存在数据库。12 项后端测试通过。
