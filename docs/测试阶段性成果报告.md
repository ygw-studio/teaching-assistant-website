# 测试阶段性成果报告

## 1. 目标

本轮测试主要验证知序教学辅助网站的基础功能是否可以稳定运行，重点覆盖学生、教师、管理员三类角色的核心链路，并检查在线 Python 与 AI 助教相关能力是否可用。

## 2. 测试范围

- 后端服务健康状态
- 学生、教师、管理员登录
- 课程读取与实验指导读取
- 管理员查看账号
- 学生权限隔离
- 在线 Python 执行与中文输出
- AI 助教基础交互能力

## 3. 测试方式

### 手工测试

- 学生端页面浏览与交互
- 教师端内容管理入口检查
- 管理员端账号管理入口检查
- 在线练习区界面和悬浮 AI 助教交互检查

### 自动化冒烟测试

执行脚本：

```powershell
cd E:\codex\教辅网站开发
.\backend\.venv\Scripts\python.exe .\tools\smoke_check.py
```

脚本覆盖：

- 后端健康检查
- 三角色登录
- 学生读取课程
- 管理员查看账号
- 学生越权拦截
- 实验指导读取
- 在线 Python 中文输出

## 4. 当前结果

### 已通过

- 后端服务可正常响应
- 三角色账号可登录
- 学生可读取课程数据
- 管理员可查看账号列表
- 学生访问管理员接口会被拦截
- 实验指导可读取
- 在线 Python 可返回中文输出结果

### 已修复问题

- 实验指导缺失导致读取失败
- `input()` 场景下标准输入不足导致 `EOFError`
- AI 助教关闭后入口不明显，误以为组件消失
- AI 助教拖动位置刷新后未保存
- Python 实验页面中悬浮窗与界面模块互相遮挡

## 5. 当前结论

当前版本已经通过基础功能所需的关键测试，可以作为课程验收、阶段开发和后续上线前的初版基础。正式上线前仍需补充更完整的异常测试、安全测试、部署环境测试和代码运行隔离测试。
