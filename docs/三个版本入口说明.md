# 三个版本入口说明

更新日期：2026-10-06。

## 入口与功能

| 版本 | 本机入口 | 工作台内容 |
| --- | --- | --- |
| 学生版 | http://127.0.0.1:4173/student | 课程讲义、知识点小测、Notebook 练习、课堂习题、AI 助教 |
| 教师版 | http://127.0.0.1:4173/teacher | 课程与讲义管理、实验管理、发布作业与截止时间、所授课程的学生记录 |
| 管理员版 | http://127.0.0.1:4173/admin | 用户管理、课程负责人和学生名单、全平台学习记录、数据处理与导出 |

学生入口使用普通登录页面，只显示“欢迎登录”、账号、密码和“登录”，不显示“学生版”“学生登录”或仅支持学生账号的提示，也没有教师或管理员的登录按钮。教师和管理员分别使用自己的网址。三个版本不是三套数据库：教师发布的教学内容仍由学生学习，数据归属和权限由后端处理。

学生端不展示学习时长。后台继续记录和汇总，教师和管理员仍可在学习记录中查看。

学生仅可下载教师课件，并在线预览讲义；课程学习和在线练习不提供配套教材资源下载，后端资源接口也拒绝学生访问。配套资源文件保留，教师和管理员仍有访问权限。

## 登录规则

- 入口决定版本，不再由用户点击身份选项决定。
- 对应身份的账号和密码不变；本次没有新建或重置真实账号。
- 账号和密码即可登录，不要求绑定手机号。个人中心不展示手机号绑定项；管理员创建账号时联系电话可留空，已有联系方式仍保留。
- 输入其他身份的账号会被拒绝。仅改网址、请求中的身份字段，不能获得对应角色权限。
- 登录状态按版本单独保存，三个版本可同时在同一浏览器不同标签页打开；退出教师版不会退出学生版或管理员版。
- 刷新后向后端验证账号和版本，不直接相信本地缓存的身份。
- 原来的自动体验登录和前端身份切换已取消。旧的全局体验令牌不会自动沿用，因此首次进入新版本需要重新登录。
- 原有根地址和 `/frontend/dist/` 地址进入学生版；章节查询参数保留。

## 启动与部署

后端仍使用 8001 端口，前端预览使用 4173 端口。启动命令见根目录 README。`tools/start_backend.cmd` 默认关闭免密码体验入口。

正式部署时，三个前端路径都要回落到同一个 `index.html`，同时保持 API 和静态资源路径正常。这些网址现在是本机入口，并不代表已发布到公网。管理员入口独立不能替代密码强度、HTTPS 和服务端授权。

## 验证方法

1. 分别打开三个网址：学生入口显示普通登录框，教师和管理员入口仍显示各自名称；三者均无身份切换按钮。
2. 用学生账号登录学生版，再拿同一账号尝试登录教师版和管理员版，应被拒绝。
3. 在三个标签页分别登录；刷新各页面并退出其中一个版本，另外两个版本应不受影响。
4. 学生读取讲义、运行 Notebook、提交课堂习题；教师查看相应课程的记录；管理员查看和导出记录。

自动化测试覆盖入口映射、版本令牌隔离、刷新用身份校验、错误身份登录、请求头伪造、退出隔离和学生无权访问全平台原始数据。现有课程、草稿、Notebook、作业、个人 API Key 与学习行为测试一起做回归。

浏览器页面自动读取受到当前工具的访问限制，页面视觉与点击验收需人工确认，不能用构建成功代替。

## 本次验证结果

- 前端：26 项测试通过，含新增的 7 项版本入口和会话隔离测试。
- 后端：31 项测试通过，含新增的 7 项版本登录和服务端权限测试；同时回归了真实 Notebook 内核、讲义、草稿、小测、截止时间、个人密钥与行为记录。
- 构建：Vite 生产构建通过。
- 本地服务：4173 前端和 8001 后端监听正常；后端健康检查返回 `ok`，免密码体验入口为关闭状态。
- 数据：测试使用临时数据库，没有向真实数据库创建测试学生、测试提交或虚构学习记录。
- 尚未验证：三个登录页的人工视觉和点击验收、正式部署与多人并发负载。这次拆分不等于已完成公网部署。
